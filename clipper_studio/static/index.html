    A different video link clears the existing metrics when saved. Add the new video's metrics after saving.

    Import analytics

    Use a per-video YouTube Studio CSV (not a daily totals or chart export) or JSON. Match existing records by published YouTube URL or video ID. To link one new CSV row, select its rendered highlight in the form.

    JSON format

    Include job_id, clip_id, publish_url and an optional metrics object; use one object or an array. CSV can also include Job ID and Clip ID columns. IDs appear after selecting a rendered highlight.

    {"job_id":"job123","clip_id":"clip456",
 "publish_url":"https://youtu.be/AbCdEf12345",
 "metrics":{"views":120,"average_percentage_viewed":73}}

    Recommendation calibration

    Comparable average percentage viewed measurements can slightly adjust the scoring weights for future recommendations. Use similar reporting windows and audiences when comparing clips. Group trends are suggestions for future edits, not proof of causation.
